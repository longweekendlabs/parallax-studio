# Certificate bundle for the model downloads. A PyInstaller build ships its own
# libssl, which looks for certificates where the build machine kept them; on a
# system that files them elsewhere there is no store and every download fails
# on verification before it starts. Carrying certifi removes that dependency.

# downloaded on first use, not bundled.
